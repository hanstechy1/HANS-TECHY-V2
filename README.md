## ⚙️ CONFIGURATION VARIABLES (CONFIG VARS)

Configure the following environment variables in your Heroku App settings (**Settings ➡️ Reveal Config Vars**):

| Variable | Description | Example |
|---|---|---|
| **`SESSION_ID`** | Your generated Session ID *(Required)* | `HANS TECHY~eyJub2lz...` |
| **`OWNER_NAME`** | The bot owner's display name | `HANS TECHY` |
| **`OWNER_NUMBER`** | Owner WhatsApp phone number without `+` | `255686005775` |
| **`PREFIX`** | Command prefix symbol | `.` |
| **`BOT_NAME`** | The display name for your bot | `HANS TECHY V2` |

> 💡 **IMPORTANT:** After deployment finishes, open the **Resources** tab in your Heroku Dashboard, disable the `web` dyno, and **turn ON the `worker` dyno**.

## ✨ KEY FEATURES

- 🤖 **AI Integration:** ChatGPT, Gemini, Copilot, LLaMA, AI Summarizer, and Code Debugger.
- ❤️ **Status Automation:** Auto-view and auto-like WhatsApp status updates.
- 👥 **Group Management:** Tagall, Hidetag, Kick, Add, Mute, Welcome, Goodbye, Antilink.
- 🎨 **Media & Stickers:** Convert photos/videos to animated stickers and image filters.
- 📥 **Media Downloaders:** Fast downloads from TikTok, YouTube, Instagram, Facebook, and Spotify.
- 🛠️ **Utility Tools:** Math calculator, weather forecasts, currency converter, QR code generator.
